# かじた式スロット

3つの数字を回して「いい数字」を引き当てる、語呂合わせ占いスロット。

- 数字をタップ、または「ストップ」で左から順に停止
- 3桁ぜんぶに語呂合わせ＋ポジティブなコメント（全1000通り）
- 当たりは **レア / スーパーレア** の2段階で派手に演出
- 出た組み合わせを GitHub の草風タイル（1000ドット）で記録

単一HTML（`index.html`）で動作します。

## Googleアナリティクス
`index.html` 冒頭の `GA_ID` を自分のGA4測定ID（`G-`から始まる）に書き換えると有効化されます。
